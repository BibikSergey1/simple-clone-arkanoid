# Simple Arkanoid Clone (Qt5 / C++)

Классическая аркадная игра «Арканоид», написанная на C++ с использованием фреймворка Qt5. Управляйте платформой, отбивайте мяч, разрушайте кирпичи и собирайте бонусы.

## 🎮 Особенности

- **Полная физика отскока**: мяч взаимодействует с платформой, стенами и блоками.
- **Уровни**: последовательное разрушение всех блоков переводит на следующий уровень.
- **Бонусы**:
  - 🔴 Красная звезда – разделение мяча на 3 шара (multi-ball).
  - 🟢 Зелёная звезда – временное увеличение платформы (симметричное расширение).
- **Летающая тарелка**: вражеский объект, который перемещается случайным образом и уклоняется от блоков.
- **Плавное управление**: клавиши влево/вправо.
- **Сохранение жизней**: три жизни, потеря при пропуске мяча.
- **Отрисовка через спрайты**: все объекты – потомки класса `Sprite` с поддержкой коллизий, анимации и граничного поведения (отскок, удаление, остановка).

## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| ←       | Движение платформы влево |
| →       | Движение платформы вправо |
| P       | Пауза |
| Esc       | Выход из игры |

## 🧱 Игровые объекты

- **Блоки**: несколько типов (обычные, синие, двойной прочности, повреждённые, неубиваемые).
- **Платформа**: управляемая полоса внизу экрана.
- **Мяч**: физика отскока, может размножаться (бонус).
- **Летающая тарелка**: движется по экрану, избегая блоков, отталкивает мяч при столкновении.
- **Стены**: декоративные границы (верхняя, левая, правая) – не создают коллизий, коллизии обрабатываются через `m_bounds`.

## 🛠️ Сборка

### Требования

- Qt 5.15 или новее (MinGW / MSVC / GCC)
- Компилятор с поддержкой C++11

### Инструкция

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/BibikSergey1/simple-clone-arkanoid.git
   cd simple-clone-arkanoid

2. Откройте проект в Qt Creator (файл .pro) или соберите из командной строки:   

   ```bash
   qmake
   make
3. Запустите игру:

   ```bash
   ./game_app
